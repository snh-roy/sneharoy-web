
# Sneha's website

I don't spend much time focused on frontend development, but I wanted to learn enough to build something real. I chose React, TypeScript, Tailwind CSS, and Vite because they're common tools in web development, and building a personal website gave me a way to learn them by using them.

A personal website felt like the right project: I could get it running quickly, make it my own, and keep improving it as my career expands in life. I have loved working on it as it let me practice an engineering rhythm: make a change, check that it works, and publish it.

[Visit the website](https://snh-roy.github.io/sneharoy-web/#/)
